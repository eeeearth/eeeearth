# Earth systems: a field guide to a changing world

**Author: eeeearth · 2026-10-02 · Version 1 · Draft · Readers: students and curious readers · 2 minutes**

Water, air, rock and living things affect one another. Follow a drop of rain, a leaf or a bit of soil to see how. Each page includes a process map and shows where eeeearth modules fit.

**Model limit:** these maps teach real science. The module labels describe a local-scene simulation with incomplete Earth-system coverage. A label beside a scientific step does not mean the simulation calculates that whole step.

**Graph key:** arrows show the direction of water, matter or energy named in each caption. `Current` means part of the live scene pipeline. `In development` means code exists but is not established in the live broadcast. `Planned` marks a design-stage module. `Possible` marks a suggested role, not a commitment. Grey nodes use the words `Planned` or `Possible` so status remains clear without color.
