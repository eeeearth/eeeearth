# eeeearth

eeeearth is a live simulation of local scenes with plants, animals, weather and sound. Watch the [live stream](https://www.youtube.com/@jt55401/live), then explore the [Earth systems guide](docs/earth-systems/README.md) to learn the science behind these scenes.

The guide's diagrams explain processes in the real world. Their module labels show what parts of the simulation exist now and what may be added later. The model covers local scenes; it does not reproduce every Earth system or every link between them.

## Modules

| Module | Role | Status |
| --- | --- | --- |
| [treeeees](https://github.com/eeeearth/treeeees) | Builds plant shapes from species records. | Current |
| [beeees](https://github.com/eeeearth/beeees) | Describes animals and their seasonal behavior. | Current |
| [breeeeze](https://github.com/eeeearth/breeeeze) | Provides weather and regional climate for scenes. | Current |
| [seeeeds](https://github.com/eeeearth/seeeeds) | Holds species, habitat and food-web data. | Current |
| [tweeeets](https://github.com/eeeearth/tweeeets) | Makes weather and animal sound. | Current |
| [streeeam](https://github.com/eeeearth/streeeam) | Relays the live scene and commentary. | Current |
| [deeeecomp](https://github.com/eeeearth/deeeecomp) | Develops living soil layers, water, temperature, decay and nutrients. | In development |
| [fungeeee](https://github.com/eeeearth/fungeeee) | Develops fungal records and underground networks. | In development |
| [licheeeens](https://github.com/eeeearth/licheeeens) | Plans lichens, mosses and biological soil crusts. | Planned |
| [geeeeo](https://github.com/eeeearth/geeeeo) | Plans rocks, bedrock and soil parent-material context. | Planned |

“Current” means used in the live scene pipeline. “In development” means code exists but the feature is not established as part of the live broadcast. “Planned” means the module is at the design stage. The four newer public repositories are short project descriptions; their private implementation is not published here.
